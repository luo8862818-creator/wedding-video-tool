# Wedding Video Tool

Windows 本地 HTML 婚礼邀请函视频导出工具。Playwright 负责网页逐帧渲染，FFmpeg 编码 H.264 并合成音乐。

## 当前导出流程
- Playwright 按邀请函时间轴逐帧渲染。
- 每帧以 JPEG 缓冲区形式输出，不再把数千张 PNG 写入临时目录。
- JPEG 数据通过 Node.js 子进程 stdin 管道直接交给 FFmpeg。
- Node.js 根据 stdin 背压等待 FFmpeg 消费数据，避免无限堆积帧数据。
- FFmpeg 同时完成 H.264 编码和可选背景音乐合成。
- 控制台记录总耗时、平均 FPS、页面时间轴调用耗时和截图耗时。

## 安装与启动
```powershell
npm install
npx playwright install chromium
npm start
```
打开 http://127.0.0.1:3000

## 使用
1. 选择包含根目录 index.html 的完整婚礼请柬项目文件夹，或填写 HTML 完整路径。
2. 可选导入本地背景音乐。
3. 设置比例、帧率、基准时长和播放速度。
4. 导出完成后可在页面内播放或下载 MP4。成品位于 output 目录。

## 性能说明
- 当前为确定性逐帧渲染方案，需对每一帧执行网页时间轴更新并截图。1080×1920、30 FPS、118 秒共 3540 帧。
- 新版将 PNG 临时文件改为 JPEG 内存缓冲区 + FFmpeg stdin 管道，减少 PNG 压缩与磁盘读写。
- 该优化不会消除 Chromium 每帧渲染/截图的成本；实际速度必须用同一份项目、同一台电脑进行 A/B 测试。
- 控制台会输出 avgFps 和各阶段耗时，可用于判断截图与页面时间轴哪个更慢。
- 若截图仍然是瓶颈，下一阶段应考虑专门的浏览器捕获/渲染架构，而不是盲目增加并发。单页面并行截图可能导致帧顺序错乱、动画状态竞争和内存占用上升。

## 速度与时长
最终时长 = 基准时长 ÷ 播放速度。基准时长 60 秒时，0.5×=120 秒、1×=60 秒、1.5×=40 秒、2×=30 秒。最终时长必须为 5～300 秒。

## 本地文件说明
- 项目素材导入到 workspaces 目录。
- 输出视频保存在 output 目录。
- 服务仅绑定 127.0.0.1，不要暴露到公网。
