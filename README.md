# Wedding Video Tool

Windows 本地 HTML 婚礼邀请函视频导出工具。Playwright 负责网页逐帧渲染，FFmpeg 合成 MP4。

## 本次更新（1.1.0）
- 可直接选择完整邀请函项目文件夹，保留 HTML、CSS、JS、图片、字体等相对目录结构。
- 可选择本地音乐文件，上传到本机临时工作区并混入 MP4。
- 增加 0.5×、0.75×、1×、1.25×、1.5×、2×速度选择。最终视频时长 = 基准时长 ÷ 速度。
- 导出完成后页面内显示 HTML5 视频播放器，可直接播放、拖动进度、调节音量和下载。
- 页面显示最终时长估算；渲染滚动使用平滑缓动，减少开始/结束突兀感。

## 安装
```powershell
npm install
npx playwright install chromium
```

## 启动
```powershell
npm start
```
打开 http://127.0.0.1:3000

## 使用
1. 点击“选择文件夹”，选择包含根目录 index.html 的整个婚礼邀请函项目文件夹。请勿只选择 index.html，否则相对图片、字体和 CSS 文件无法完整导入。
2. 可选选择音乐文件。
3. 选择比例、帧率、基准时长和速度。
4. 速度越大，最终视频越短、页面滚动越快；速度越小，最终视频越长、页面滚动越慢。
5. 等待导出完成，在右侧视频播放器直接播放或下载 MP4。成品位于项目 output 目录。

## 速度计算示例
基准时长 60 秒：
- 0.5× → 120 秒
- 1× → 60 秒
- 1.5× → 40 秒
- 2× → 30 秒

最终时长限制为 5～300 秒。支持 25/30/60 FPS。高分辨率、复杂动画和大量大图会明显增加渲染时间。

## 注意
- 文件选择通过本地 HTTP 上传到本机 workspaces 目录，不会上传到第三方服务。
- 上传完整文件夹以保留素材相对路径。工作区文件不要手动删除，重新选择项目会生成新的工作区。
- 当前渲染是自动从网页顶部滚动到底部；不会自动解析用户页面里的复杂分镜时间轴。
- 本地服务仅绑定 127.0.0.1，不要暴露到公网。
- output/ 和 workspaces/ 已加入 Git 忽略建议，生成视频和用户素材不要提交到仓库。
