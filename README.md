# Wedding Video Tool

Windows 本地 HTML 婚礼邀请函视频导出工具。Playwright 负责网页逐帧渲染，FFmpeg 合成 MP4。

## 功能
- 直接选择完整项目文件夹，按相对路径导入 HTML、CSS、JS、图片、字体等素材。
- 可选导入本地音乐，混入最终 MP4。
- 速度控制：0.5×、0.75×、1×、1.25×、1.5×、2×。
- 导出完成后显示内嵌视频播放器，可播放、暂停、拖动进度、调节音量和下载。
- 对接婚礼请柬项目的 weddingPlayer 时间轴：逐帧驱动同一条分镜/滚动时间线，不再用无视页面原始时间轴的“极速滚到底”方式。
- 普通 HTML 页面没有 weddingPlayer 时，使用平滑滚动作为兼容模式。

## 安装与启动
```powershell
npm install
npx playwright install chromium
npm start
```
打开 http://127.0.0.1:3000

## 使用
1. 点击“选择文件夹”，选择包含根目录 index.html 的整个婚礼请柬文件夹。
2. 等待项目导入完成。资源目录结构会被保留。
3. 可选选择背景音乐。
4. 设置比例、帧率、基准时长和播放速度。
5. 导出完成后直接在右侧播放，或下载 MP4。

## 速度说明
最终时长 = 基准时长 ÷ 播放速度。基准时长 60 秒时，0.5×=120 秒、1×=60 秒、1.5×=40 秒、2×=30 秒。最终时长必须为 5～300 秒。

速度控制的是成片播放速度：请柬时间轴会从开始完整走到结束，只是映射到不同的成片时长，不会跳过后半段内容。

## 运行说明
- 选择文件夹和音乐时，浏览器把文件传给本机 127.0.0.1 服务，文件只保存在本机 workspaces 目录，不会传到第三方。
- 输出视频保存在 output 目录。
- 服务仅绑定 127.0.0.1，不要暴露到公网。
- 逐帧渲染速度受素材尺寸、动画复杂度、输出分辨率和电脑性能影响；渲染耗时不等于成片时长。
