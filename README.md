# Wedding Video Tool

Windows 本地 HTML 婚礼邀请函视频导出工具。Playwright 负责网页逐帧渲染，FFmpeg 编码 H.264 并合成音乐。

## 当前导出流程
- 对普通自动滚动网页，Playwright 使用真实浏览器时钟运行，不接管网页定时器和 requestAnimationFrame；自动检测按真实时间测量滚动完成时长。
- 普通网页导出按真实墙钟时间采样，输出帧槽固定为目标 FPS；截图赶不上时重复上一帧补齐时间槽，避免网页因截图耗时而被虚拟时钟拖慢或提前播放完。
- 对提供 weddingPlayer.renderAt() 的确定性时间轴网页，仍按时间轴接口逐帧渲染，并根据播放速度映射时间。
- 每帧以 JPEG 缓冲区形式输出，不再把数千张 PNG 写入临时目录。
- JPEG 数据通过 Node.js 子进程 stdin 管道直接交给 FFmpeg。
- Node.js 根据 stdin 背压等待 FFmpeg 消费数据，避免无限堆积帧数据。
- FFmpeg 同时完成 H.264 编码和可选背景音乐合成。
- FFmpeg 通过进度输出报告实际编码帧数；编码帧数与计划帧数不一致时，任务判定失败，不交付不完整视频。\n- 控制台记录总耗时、平均 FPS、页面时间轴调用耗时、截图耗时、滚动位置与关键帧校验结果。

## 安装与启动
```powershell
npm install
npx playwright install chromium
npm start
```
打开 http://127.0.0.1:3000

## 使用
1. 选择包含根目录 index.html 的完整婚礼请柬项目文件夹，或填写 HTML 完整路径。
2. 可选导入本地背景音乐。
3. 设置比例、帧率、基准时长和播放速度。
4. 导出完成后可在页面内播放或下载 MP4。成品位于 output 目录。

## 性能说明
- 当前为确定性逐帧渲染方案，需对每一帧执行网页时间轴更新并截图。1080×1920、30 FPS、118 秒共 3540 帧。
- 新版将 PNG 临时文件改为 JPEG 内存缓冲区 + FFmpeg stdin 管道，减少 PNG 压缩与磁盘读写。
- 该优化不会消除 Chromium 每帧渲染/截图的成本；实际速度必须用同一份项目、同一台电脑进行 A/B 测试。
- 控制台会输出 avgFps 和各阶段耗时，可用于判断截图与页面时间轴哪个更慢。
- 当前优先保证正确性，使用单页面顺序采集，避免多个页面并行时出现时间轴状态竞争。确认成片正确后，再单独评估性能优化。

## 速度与时长
普通自动滚动网页的自动检测使用真实浏览器时间，记录网页原本的滚动速度和到达底部后的稳定停留时间。导出时不再使用虚拟时钟推进网页，而是让网页自然播放并按真实时间采样；如果截图处理速度低于目标 FPS，会重复上一帧补齐视频时间槽，因此视频时长和滚动速度不会因渲染慢而被压缩，但可能出现轻微卡顿。

手动设置时长仍可用于没有自动滚动或无法识别结束状态的网页。对于 weddingPlayer 时间轴，播放速度通过时间轴采样位置映射。

## 本地文件说明
- 项目素材导入到 workspaces 目录。
- 输出视频保存在 output 目录。
- 服务仅绑定 127.0.0.1，不要暴露到公网。
