# Wedding Video Tool

Windows 本地 HTML 婚礼邀请函视频导出工具。Playwright 负责真实运行并录制浏览器画面，FFmpeg 负责转换 MP4、统一帧率和合成可选背景音乐。

## 当前导出流程

1. 导入单个 HTML 文件，或导入包含 index.html 的完整项目文件夹。
2. Playwright 启动 Chromium，通过本地 HTTP 服务打开网页。
3. 浏览器按网页自身的 JavaScript、CSS、定时器和 requestAnimationFrame 正常运行；工具不接管虚拟时钟、不修改滚动速度。
4. Playwright recordVideo 记录真实浏览器画面。网页慢速、快速、分段停顿和启动延迟都保留在录制时间轴中。
5. 工具监测原生滚动容器、CSS transform 内容位移和页面完成标记，自动判断录制结束。
6. FFmpeg 将浏览器录制文件转换为 H.264 MP4，输出目标分辨率与 FPS，并将可选音乐从视频起点合成到视频结束。
7. 对 MP4 进行完整解码校验，读取实际帧数和时长。只有校验通过后才替换正式输出文件。

## 安装与启动

```powershell
npm install
npx playwright install chromium
npm start
```

打开 http://127.0.0.1:3000

## 使用

- **单文件网页**：点击“选择 HTML 文件”，适用于 CSS、JavaScript、图片等资源全部内嵌在 HTML 中的独立文件。
- **完整项目**：点击“选择文件夹”，适用于引用外部 CSS、JS、图片、字体、音频等资源的网页；所选文件夹根目录必须有 index.html。
- 可选选择背景音乐；音乐从最终视频起点开始，循环或裁剪到网页录制结束。
- 选择画面比例、FPS 和输出文件名，点击“开始真实播放并导出 MP4”。
- 不需要提前检测时长，也不需要手动填写视频秒数。
- 导出完成后可在页面内播放或下载 MP4。成品保存在 output 目录。

## 同步原则

- 网页负责播放，录制器负责记录；不使用固定总时长把网页滚动强行平均分配。
- 页面每一段实际花费多少时间，视频就保留多少时间；中间停顿也会录入。
- FFmpeg 的 FPS 转换只做帧率采样/补帧，不改变视频时间轴时长。
- 如果浏览器录制帧率或电脑性能不足，成片可能出现重复帧或轻微卡顿，但不会通过加速网页来掩盖性能不足。
- 背景音乐以最终录制视频时长为边界，结束时同步裁剪。

## 自动结束判断说明

结束判断按以下优先级执行：

1. 页面出现明确的播放完成标记。
2. 已经实际发生过滚动的容器到达底部，并等待末尾动画结束及短暂稳定。
3. CSS transform 驱动的长内容移动到末尾，并等待稳定。
4. 没有滚动容器的分屏动画，在长时间没有可检测的画面位移后结束。

自动结束判断是对普通自动播放网页的通用启发式检测。若网页存在超过 15 秒的章节间停顿、循环动画、滚动循环或非常规画面切换，工具可能无法仅凭网页结构准确推断“创作者认为的结束时刻”。此时应调整网页的播放结束行为，或在后续版本增加可配置的结束条件。单纯选择一个 HTML 文件不会自动包含它引用的外部资源；如网页依赖外部素材，请导入完整文件夹。

## 输出与校验

- 默认输出：1080 × 1920、30 FPS、H.264、MP4。
- 不预先计算 ceil(时长 × FPS) 作为必须匹配的帧数，避免小数时长产生最后一帧的 ±1 帧误报。
- FFmpeg 转码到临时文件；完整解码校验通过后，才替换 output 目录中的正式 MP4。
- 导出历史记录保存实际视频时长、帧数、平均 FPS、导出耗时和结束判断原因。

## 本地文件说明

- 项目素材导入到 workspaces 目录。
- 输出视频保存在 output 目录。
- 浏览器临时录制文件使用系统临时目录，任务结束后清理。
- 服务仅绑定 127.0.0.1，不要暴露到公网。
